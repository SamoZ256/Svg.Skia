    UnoDraw MCP tool reference

    This reference contains all 56 tools from the executable catalog. It is generated by scripts/generate_unodraw_mcp_docs.py; update the C# catalog and regenerate this page when an input schema changes.

    See the connection and workflow guide for desktop/browser setup, resources, prompts, document identities, revision checks, export content blocks, read-only mode, cancellation and troubleshooting.

    All calls use MCP tools/call with the listed tool name and an arguments object. Names and enum values are case-sensitive. Required fields below describe the schema; action-specific operations can require additional fields described by the tool. Complete nested schemas follow each argument table. Mixed read/write tools require an editing connection even when invoked with a read action.

    unodraw_element_reparent Editing Move/reorder branches while preserving world position and references using the editor hierarchy controller.

    unodraw_guide_edit Editing Add, move, remove or clear guides, or create guides from selection bounds.
    unodraw_guide_list Inspection/export List nonprinting native guides in picture coordinates.
    unodraw_layer Editing Create a native editor layer, change its display name, or set an element's own visibility/lock while retaining selection. Inherited locks must be changed on the parent.
    unodraw_measure Inspection/export Measure a picture-coordinate segment in root SVG units, accounting for viewBox transforms. Does not change selection or artwork.
    unodraw_mesh Editing Read or apply native gradient-mesh XML, or create a mesh grid. Mesh data retains editable control points and rendering quality. Setting an explicit element requires a compatible group; omit the element to create a mesh when no group is selected.
    unodraw_paint Editing Set selection fill, stroke, stroke width, opacity and SVG appearance attributes. With no selection fill/stroke become current drawing paints.
    unodraw_path Editing Edit selected paths with native offset, anchor, scissors, knife, eraser, smooth/join, blob, deformation or shape-builder algorithms.
    unodraw_preflight Inspection/export Inspect missing references, duplicate IDs, fonts, images, text overflow and print readiness with native preflight.
    unodraw_print_export Inspection/export Export physical-page PDF or CMYK/spot separation ZIP using native print settings and quality. Optional base64 ICC profile enables profiled CMYK conversion. Returns binary data; does not print to a device.
    unodraw_print_get Inspection/export Read complete native print settings XML and physical page layout.
    unodraw_print_set Editing Validate and apply native print settings XML as an undoable document edit. Includes physical sizes, bleed, margins, tiling, marks, RGB/CMYK and ink limits.
    unodraw_resource_import Editing Import one SVG resource using existing collision-free ID/reference remapping. Returns the actual adopted resource ID.
    unodraw_resource_list Inspection/export Inspect all defs resources, document CSS, brushes, symbols, gradients, patterns and masks using element keys and XML.
    unodraw_selection_get Inspection/export Read selected element keys, rendered bounds and revision.
    unodraw_selection_set Editing Select by explicit element keys, point, rectangle, lasso, appearance, all, inverse, or same-property matching. Coordinates are picture units.
    unodraw_shortcuts_get Inspection/export Read the complete keyboard profile XML and resolved command shortcuts.
    unodraw_shortcuts_set Editing Validate and persist a native keyboard shortcut profile, or reset to defaults.
    unodraw_symbol Editing Spray symbol instances or apply native shift, scrunch, size, spin, stain, screen and style brushes.
    unodraw_text Editing Edit selected text and typography, or create text on the selected path / in a bounded text area.
    unodraw_text_story Editing Read or replace complete paragraph/linked-frame story XML using the native text-story serializer. Set xml to apply; omit to read. An explicit element must belong to a text story. Without an explicit element, XML creates a story when none is selected.
    unodraw_timeline_edit Editing Set preview time, bake a frame, create/delete tracks, or set keys through the native animation service.
    unodraw_timeline_get Inspection/export Read native animation tracks and current preview time. XML editing covers every SVG animation attribute.
    unodraw_tools_list Inspection/export Discover all editor tools, current tool, modes, and action-based tool behavior.

    unodraw_tools_select Editing Activate a discovered tool. Action-based tools use commands_run with explicit interaction; symbol spray requires a symbol ID.
